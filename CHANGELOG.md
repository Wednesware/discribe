# Changelog

## 0.1.1 — 2026-10-24

- Zoom either editor with Ctrl+scroll wheel or Ctrl+/− (Cmd shortcuts also work).
- Reset with Ctrl+0 or the zoom percentage in the status bar.
- Code and Write each remember their own zoom level, from 50% to 200%.
- Zoom changes the editing surface without resizing the application toolbar or modifying document contents.
